# Release notes template

Use this structure for future semantic releases. Keep only sections that apply.

```markdown
## Highlights

- The most important user-facing or architectural outcomes.

## Added

- New capabilities introduced by this release.

## Changed

- Relevant behavior or maintenance changes.

## Fixed

- Defects resolved by this release.

## Quality

- Tests, coding standards, CI, or security validation performed.

## Requirements

- PHP 8.1+
- WordPress 6.5+
- Docker and Docker Compose for local development

## Upgrade notes

- Any action required after updating, or "No manual migration required."
```
